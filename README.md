## proyecto usando javaScrip, boostrap, html, css, mysql, express

    -Lo primero que se ejecuta para tener todos los paquetes de js es --->  npm init -y
    -despues instalamos express para el servidor                      ---> npm install express
    -instalamos una configuracion para usar .env en el proyecto       ---> npm install express mysql2 dotenv
    en el backen impostante instalar cors para que me deje hacer peticiones --> npm install cors
